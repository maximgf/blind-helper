# vl53l0x_gy530

Драйвер модуля **GY-530** (чип **STMicro VL53L0X**) как реализация [distance_sensor](../../distance_sensor/README.md).

## Принцип измерения

**Time-of-Flight (ToF)**: импульс лазера 940 nm, измерение времени до отражения → дистанция вдоль **оси модуля** (куда смотрит датчик на корпусе).

- Один вызов `read_mm` → один снимок `vl53l0x_read_range_single_mm()`.
- Диапазон чипа: порядка **до ~2 m** (зависит от режима и отражения).
- Прикладная зона alert ограничена [app_config](../../app_config/README.md) (`zone_max`, по умолчанию 1 m).

## Аппаратная конфигурация

| Сигнал | GPIO / параметр |
|--------|-----------------|
| I2C SDA | 4 |
| I2C SCL | 5 |
| XSHUT | 7 (сброс/пробуждение) |
| Порт I2C | `I2C_NUM_0` |
| Адрес 7-bit | `0x29` |
| Частота | 100 kHz |
| Таймаут I/O | 500 ms |
| Режим I/O | 2V8 (`VL53L0X_GY530_IO_2V8_MODE`) |

### Последовательность init

1. XSHUT LOW 100 µs → HIGH, пауза 2 ms (выход из shutdown).
2. `i2c_new_master_bus`, устройство на `0x29`, probe.
3. `vl53l0x_init()` — калибровка и настройка через низкоуровневый `vl53l0x.c`.

## Протокол I2C (транспорт)

| Параметр | Значение |
|----------|----------|
| Шина | ESP-IDF `i2c_master` (driver/i2c_master.h) |
| Адресация | 7-bit, `0x29` |
| Регистры | 16-bit индекс, big-endian адрес в `vl53l0x.c` |
| Чтение/запись | Блоки через `i2c_master_transmit` / `receive` |

Детали регистров VL53L0X инкапсулированы в `vl53l0x.h` / `vl53l0x.c` (порт Pololu).

## Протокол данных (к приложению)

| Поле | Тип | Описание |
|------|-----|----------|
| `mm_out` | `uint16_t` | Миллиметры по лучу |
| Ошибка | `DISTANCE_MM_INVALID` (65535) + `ESP_ERR_INVALID_RESPONSE` |
| Успех | `ESP_OK` |

## API

```c
esp_err_t vl53l0x_gy530_get(distance_sensor_t *out);
```

Имя сенсора: `"GY-530 (VL53L0X)"`.

## Ограничения и шум

- Блики, чёрные/прозрачные поверхности → invalid.
- Для устойчивости alert используется [hazard_filter](../../hazard_filter/README.md), а не порог по одному кадру.
